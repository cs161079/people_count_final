# 🚌 Τηλεματική ΟΑΣΑ – Raspaberry People Count
Το παρόν project αποτελεί το μέρος διπλωματικής με θέμα **Τηλεματική Λεvφoρείων με Χρήση τεχνιτής νοημασύνης**. 
To Project αυτό γίνεται Deploy σε ένα Raspberry PI το οποίο θα είναι τοποθετημένο στο λεωφορείο. Συνδεόντας μία κάμερα για κάθε πόρτα θα γίνεται καταμέτρηση των επιβατών αποστέλοντας αυτή την πληροφορία στον Application Server. 
## Βήματα εγκατάστασης του προγράμματος
1) Clone το Repository στο Raspberry PI
2) Άνοιγμα του καταλόγου στο terminal
3) Παραμετροποιούμε - Ρυθμίζουμε σωστά το αρχείο .env σύμφωνα με τις οδηγείες
```
vi .env
```
4) Δημιουργία virtual enviroment και ενεργοποιήση αυτόυ
```
python -m venv venv
venv\Scripts\Activate
```
5) Κάνουμε εγκατάσταση όλων των απαραίτητων βιβλιοθηκών - πακέτων
```
pip install -r requirements.txt
``` 
6) Τέλος εκτελούμε
```
python main.py
```

**Σημείωση!**
Στο Raspbery PI χρησιμοποιεί την opencv-python-headless, η οποία είναι χωρίς GUI. Σε άλλες περιπτώσεις μπορείς να χρησιμοποιηθεί και το opencv-python.
